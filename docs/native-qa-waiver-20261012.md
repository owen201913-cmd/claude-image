# 乾淨 Windows 測試停止紀錄

2026-10-12，擁有者表示「我累了，不想做 Windows 測試了，我只想趕快做好」。因此乾淨 Windows P4 生命週期記為 **NOT_RUN_USER_WAIVED**，不再作為此次發布門檻，不標成 PASS。

一次性指定的測試映像啟動時，使用者提供 `INACCESSIBLE_BOOT_DEVICE (0x7B)` 的畫面；電腦隨後回到原 Windows 11 家用版。只有開機錯誤已觀察，原因未知。沒有完成乾淨 Windows／Claude 的安裝、更新、重啟、移除驗收。

本專案新增的唯一 QA 開機項目已移除，原 Windows 預設、等待時間及其他開機設定已核對恢復；收尾沒有再次重啟，也没有刪除磁碟或使用者檔案。離線實驗材料仍保留在私有工作資料，不包含於原始碼匯出或 MCPB。

早期 BLOCKED、NOT_RUN 和失敗報告保留為歷史，不改寫成通過。安裝者不需要 VirtualBox、測試 Windows 映像、修改開機選單或管理員權限；這些是已停止的開發實驗。
