# Claude Image 0.1.0 發布驗收

2026-10-12。擁有者決定停止乾淨 Windows 測試，允許以明確揭露的未測項目完成本機發行產物；不代表已授權公開 repository 或 Release。

## 本版與既有證據

0.1.0 延用 RC12 的生成、原圖保存、去重、取消與卡片行為，只更新版本標示、安裝說明及封裝白名單。正式版已建置；沒有新增 Ngini 提交，也沒有重跑完整測試。

- RC12 完整離線及模擬瀏覽器測試：332/332 PASS，54/54 suites；這是歷史結果，不是新版本再次執行。
- 歷史真實提交：7 次可能耗額，取得 5 份不同原圖，其中 2 份內容相符並完成原檔下載。其他結果與失敗保留，不宣稱全部生成成功或網站總生成數已知。
- 本機背景生圖、普通聊天卡片與原圖保存已有實機證據。卡片是 MCP App，不宣稱 Claude 原生附件。
- 窄用途帳號 Instructions：1 個既有圖片回覆沒有附加正文，3 個來源／一般問答／錯誤控制案例 PASS。必須另外保存帳號設定；MCPB 不會自動套用，也不能保證所有 Claude 回合都無字。

新封裝的檢查與 SHA-256 另記於同版 Release 說明及 `.sha256`。不能將封裝成功解讀為新的實機生圖或乾淨系統驗收。

本版新建置的卡片另做 1 個針對性 CSP／預覽／原檔下載模擬檢查 PASS；另外 2 個同檔案例未重跑。HTML SHA-256 為 `7455f0f52f5a9956acf1e0ee00644f8ae805b9f573f751d702ae2d5a67c11368`，此檢查不連線 Ngini，也不是 Claude Desktop 新實機驗收。

## 已揭露的免測與限制

乾淨 Windows 安裝、更新、重啟及移除生命週期：**NOT_RUN_USER_WAIVED**。實驗映像原生開機出現 `INACCESSIBLE_BOOT_DEVICE (0x7B)`，隨後回到原 Windows；原因未診斷，不把它歸因於外掛。已停止該測試，移除本專案新增的 QA 開機項目並核對原設定；沒有再重啟。

macOS、其他 Claude 版本、網頁版及手機版未實測。公開 repository、託管 CI 與 GitHub 下載仍未執行。Ngini 額度、頁面與可用性由網站決定。

初次封包核對因讀到舊通用 CSP 報告而失敗；本版測試已通過，後續只修正證據與文件關聯，保留原失敗產物，沒有重跑測試。
